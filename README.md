# hashing project
## requirements
This project requires  the ability to run C++

### description
Hashing-projects is an attempt by me to recreate the hashmaps of C++ and add onto them by making it more available to other C++ data-structures than the current limited ones.

Specifications: 

Program has the ability to hash sets, unordered sets, and recursively hash vectors.

Doubles hashtable size at 0.75 load capacity.

Program cannot currently hash itself, cannot currently hash pairs/tuples.
